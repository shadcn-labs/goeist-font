# goist

## 0.0.1

### Patch Changes

- Initial release of Goist Sans and Goist Mono 0.001, rounded derivatives of Vercel Geist Sans and Geist Mono v1.9.2, with nine weights and genuine italics each, as variable and static WOFF2 for `next/font` (`goist/font/sans`, `goist/font/sans-non-variable`, `goist/font/mono`, `goist/font/mono-non-variable`) and plain CSS (`goist/sans.css`, `goist/sans-static.css`, `goist/mono.css`, `goist/mono-static.css`).
